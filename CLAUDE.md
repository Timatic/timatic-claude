## Domain docs

Timatic's domain rules live in the backend repository under https://github.com/Timatic/timatic-backend/tree/main/docs: budgets, versions and periods; entries, locked dates and daily progress; the suggestion pipeline from events to activities to suggestions. Start with the glossary at https://github.com/Timatic/timatic-backend/blob/main/docs/GLOSSARY.md and use its terms in code and copy. Read the matching page before changing anything that touches budgets, entries or suggestions.
